Per migliorare

    Test completi in una nuova scheda:

    DNS sicuro

    Le richieste DNS viaggiano cifrate. Se il DNS scelto non risponde, i siti non si aprono: nessun ripiego in chiaro.

    Proxy e VPN

    Con una VPN attiva sul computer non serve altro. Per far passare solo il browser da una VPN o da Tor, usa il suo proxy SOCKS5 (Mullvad: 10.64.0.1 porta 1080, Tor: 127.0.0.1 porta 9050). Se il proxy cade, la navigazione si ferma.

    Il motore Chromium non supporta SOCKS5 con password: usa un proxy SOCKS5 senza accesso o un proxy HTTP.
